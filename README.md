# Миксолог — Telegram-бот подбора кальянных миксов

Клиент пишет в свободной форме, что любит и как крепко курит. Бот отвечает тремя миксами
из табаков наших брендов: один «в яблочко» и два запасных, с описанием и картинкой.
Кнопка «Ещё варианты» даёт новую тройку без повторов.

## Как это работает

1. **Разбор запроса.** ИИ превращает текст клиента в структуру: вкусы, чего избегать, бренды, крепость.
   Если крепость не названа — бот спрашивает кнопками.
2. **Отбор.** Код выбирает из справочника до 57 подходящих табаков: по вкусовым тегам, крепости и рейтингу.
3. **Сборка.** ИИ собирает из них 3 микса с долями и описанием. Код проверяет, что табаки существуют и доли дают 100%.
4. **Картинка.** К главному миксу рисуется иллюстрация (можно выключить: `IMAGES = "off"`).

## Справочник

Берётся с htreviews.org по брендам из `BRANDS`: название, линейка, крепость, рейтинг, вкусовые теги.
Снятые с производства вкусы не попадают.

- Автоматически: каждый понедельник с 06:00 МСК, по одному бренду раз в 10 минут.
- Вручную: открыть `https://mix-bot.ИМЯ.workers.dev/refresh?key=WEBHOOK_SECRET`.

Добавить бренд: дописать его в `BRANDS` так, как он назван в адресе `htreviews.org/tobaccos/<бренд>`.

## Смена мозгов

В `wrangler.toml` поменять `LLM_PROVIDER` и `LLM_MODEL`, для платных моделей добавить секрет `LLM_API_KEY`.
Остальной бот не меняется.

## Наличие (следующий шаг)

Бот уже умеет фильтровать по складу: если в KV лежит ключ `stock` со списком ключей табаков
(вида `darkside/core/supernova`), подбор идёт только из них. Осталось сделать загрузку выгрузки.

## Установка (всё в браузере)

1. **Бот.** `@BotFather` → `/newbot` → скопировать токен.
2. **Репозиторий.** GitHub → New repository `mix-bot` → загрузить `src/worker.js`, `wrangler.toml`, `README.md`.
3. **KV.** Cloudflare → Storage & Databases → KV → Create → имя `mix-bot` → скопировать ID →
   в GitHub открыть `wrangler.toml` → заменить `ЗАМЕНИТЬ_НА_ID` → Commit.
4. **Деплой.** Workers & Pages → Create → Workers → Import a repository → `mix-bot` → Deploy.
5. **Секреты.** Settings → Variables and Secrets → `BOT_TOKEN`, `WEBHOOK_SECRET` → Deploy.
6. **Вебхук.** Открыть `https://mix-bot.ИМЯ.workers.dev/setup?key=WEBHOOK_SECRET` → `"ok": true`.
7. **Справочник.** Открыть `https://mix-bot.ИМЯ.workers.dev/refresh?key=WEBHOOK_SECRET` и дождаться «Готово».
8. Написать боту `/start`.

## Ограничения

- Бесплатные модели Cloudflare: 10 000 «нейронов» в сутки на всё. Хватит на тесты, не на поток клиентов.
- Сборщик справочника проверен на реальной структуре сайта, но не с адресов Cloudflare.
  Если на шаге 7 бренд вернёт ошибку — сайт не пускает Cloudflare, нужен другой способ забора.
- Бренд SIGMA пока не подключён: не найден его адрес на htreviews.
