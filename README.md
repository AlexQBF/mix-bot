# Sigma Mix — Telegram-бот подбора кальянных миксов

Клиент пишет в свободной форме, что любит и как крепко курит. Бот присылает одну картинку
(SIGMA MIX + три круга-соуса) и три микса из табаков наших брендов: состав, доли, граммы на чашу,
описание, крепость. Кнопка «Ещё варианты» — новая тройка без повторов. Русский и армянский.

## Где что живёт

| Что | Где |
|---|---|
| Правила миксов, тексты бота, бренды, акценты, крепость, картинка, админы | **Google Таблица** (`CONFIG_SHEET_ID` в `wrangler.toml`) |
| Мозги (модель ИИ), модель картинок, ID таблицы | `wrangler.toml` |
| Токен бота, секрет вебхука, ключ платного ИИ | Cloudflare → Settings → Variables and Secrets |
| Справочник вкусов, копия настроек из таблицы, диалоги | Cloudflare KV |

## Как работает таблица

- Менеджер правит таблицу. Бот сам проверяет её раз в 15 минут, или сразу по команде `/reload`.
- Таблица проверяется перед применением. Ошибка — бот работает на прежних настройках и пишет админам, где ошибка.
- Клиентские запросы в таблицу не ходят — только в копию в KV, поэтому скорость та же.
- Если таблица недоступна совсем — работает последняя копия, а если её нет — значения по умолчанию из `worker.js` (`DEFAULTS`).
- Технический хвост задания ИИ (формат ответа, JSON) в таблицу не вынесен, чтобы его нельзя было случайно сломать.
- Доступ к таблице: «Все, у кого есть ссылка» — «Читатель» (иначе бот не прочитает), редакторы — по приглашению.

Подробная инструкция для менеджера — на первой вкладке таблицы «Как пользоваться».

## Команды

- `/start`, `/new`, `/language` — для клиентов.
- `/id` — показать свой Telegram ID (чтобы вписать себя во вкладку «Админы»).
- `/reload` — применить изменения из таблицы сейчас (админы).
- `/config` — что сейчас действует (админы).

Админам приходят уведомления: изменения из таблицы применены / в таблице ошибка / новый бренд скачан.

## Справочник вкусов

Берётся с htreviews.org по включённым брендам из вкладки «Бренды».
- Автоматически: каждый понедельник с 06:00 до 11:00 МСК, по одному бренду раз в 10 минут.
- Новый бренд, добавленный в таблицу, скачивается сам в течение ~15 минут.
- Вручную всё сразу: `https://mix-bot.ИМЯ.workers.dev/refresh?key=WEBHOOK_SECRET`.

## Смена мозгов

В `wrangler.toml` поменять `LLM_PROVIDER` и `LLM_MODEL`, для платных моделей добавить секрет `LLM_API_KEY`.

## Наличие (следующий шаг)

Бот уже умеет фильтровать по складу: если в KV лежит ключ `stock` со списком ключей табаков
(вида `deus/deus-main/guava-lychee`), подбор идёт только из них. Осталось сделать загрузку выгрузки.

## Установка с нуля (всё в браузере)

1. `@BotFather` → `/newbot` → токен.
2. GitHub-репозиторий `mix-bot`: `src/worker.js`, `wrangler.toml`, `README.md`.
3. Cloudflare → KV → Create `mix-bot` → ID в `wrangler.toml` вместо `ЗАМЕНИТЬ_НА_ID`.
4. Workers & Pages → Import a repository → `mix-bot` → Deploy.
5. Секреты `BOT_TOKEN`, `WEBHOOK_SECRET` → Deploy.
6. Открыть `https://mix-bot.ИМЯ.workers.dev/setup?key=WEBHOOK_SECRET` — вебхук + первая загрузка таблицы.
7. Открыть `/refresh?key=WEBHOOK_SECRET` — скачать вкусы.

## Ограничения

- Бесплатные модели Cloudflare: 10 000 «нейронов» в сутки на всё (~30 подборов с картинкой).
- Бесплатный KV: 1 000 записей в сутки; бот пишет 2–3 раза на сообщение. Копия таблицы пишется только при изменениях.
- Google обновляет данные таблицы для чтения с задержкой до пары минут — `/reload` сразу после правки иногда видит старое.
